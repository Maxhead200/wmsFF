# Обед и учёт погрузки / разгрузки

Версия приложения учёта времени: 0.3.0-pilot (5).

В открытой смене кнопки «Обед» и «Вернулся» фиксируют фактический перерыв, в том числе без сети. Перерывы вычитаются из оплачиваемого времени; автоматический час дополнительно не вычитается. Уход во время обеда завершает и смену, и перерыв. Повторная отправка события не создаёт дубликатов.

Четыре независимые строки: палеты, короба, мешки, рулоны. 500 ₽ за палету; эквивалент = палеты + короба/16 + мешки/5 + рулоны/30. Одни и те же грузы не нужно записывать одновременно как палеты и их содержимое. Сумма округляется до копеек в конце и делится между участниками. Начисление требует существующего подтверждения в ФОТ. Ранее подтверждённые суммы не пересчитываются.

Обновление APK сохраняет регистрацию и локальную очередь: подпись совпадает с 0.2.2-pilot, Room 1→2 имеет явную миграцию. Проверены сборка, подпись и 81 Android-тест; физический планшет не проверялся.

Сервер: добавочные PayrollBreak и четыре поля PayrollHandling. Откат runtime допускает сохранение добавленных таблиц/полей. Проданная WMS не обновляется. Общие модули attendance-device, payroll, DTO и расчёт изменены, поэтому перенос на другую ВМС требует отдельного согласования и миграции.

Проверки: API 2979, отдельный PostgreSQL attendance 15, web 355 (до дополнительного теста), затем PayrollManagement 14; Android 81, lint, TypeScript. API 129 и web 2 пропуска — отдельные окружения / ранее отключённые тесты. Целевые проверки обеда воспроизвели ошибку до правки. Runtime основан на свежем production, проверено точное совпадение прежних четырёх API-модулей с исходниками. В выпуске меняются только эти четыре модуля и новый handling-quantities; Prisma генерируется из дополненной действующей схемы. Полная локальная сборка production не заменяет.
