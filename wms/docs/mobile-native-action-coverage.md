# Нативные операции: состояние переноса 04.10.2026

Это рабочая карта, **не подтверждение полного покрытия** веб-ВМС.
Наличие пункта меню или GET списка не означает наличие всех операций раздела.

| Блок | Подтверждено в исходниках Android | Осталось проверить/перенести |
| --- | --- | --- |

| Финансовые исправления | Локально: `FinancialActionsFragment`, предварительный расчёт, подтверждение, закрытие периода, signed-корректировка, поздний черновик; сохранение незавершённого запроса | Не опубликовано, установка и реальные пользовательские сценарии не проверены |

| Волны, FBO, DBS, статистика | Полное покрытие не подтверждено | Нативные экраны и операции после сверки контрактов |
| Склад, зоны, инвентаризация, КИЗ, упаковка, переклейка | Полное покрытие не подтверждено | Каждая мутация с правами, контекстом, сканированием, подтверждением и защитой от дублей |
| Управление, логистика, печать, финансы | Частичные существующие экраны | Полная карта действий, в том числе создание/изменение/отмена, а не только просмотр |

Для допуска действия: найден фактический API → нативная форма → серверные права и
контекст → сообщения об ошибке → защита повторов → автотесты → проверка на устройстве.
Тестирование не создаёт финансовые/складские документы в production.

## Финансовые операции

Вход: «Клиенты и расчёты → Исправить счёт / закрыть период».
Нужны billing:write (или system:admin), выбранные клиент/филиал и capability сервера.
Смена контекста запрещает подтверждение прежнего расчёта. Исходные счета/оплаты
не редактируются напрямую: используются существующие server preview/hash операции.
При неизвестном результате новый документ заблокирован; только явный повтор того же
сохранённого запроса. Для корректировки сохраняется operationKey, для закрытия —
точный период и previewHash. Автоматический повтор по таймеру отсутствует.
