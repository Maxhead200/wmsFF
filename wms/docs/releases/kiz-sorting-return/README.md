Точечный выпуск нашей ВМС. База API: `sha256:12fa527baadc9a49bee0422932e49311dd96f2a8ddc32cbc4a34f0a18af92f38` (PR346).

Администратор в существующем разборе КИЗов подтверждает физическое наличие. Для прежнего заказа complete/sorted разрешается архивировать привязку завершённого задания, если точный КИЗ после отгрузки попал в текущий короб через подтверждённую сортировку. Проверяется конкретная маркировка, складское движение, клиент, SKU, короб и дата позже последней отгрузки. История отгрузки не удаляется; архивируется полная старая привязка и доказательства сортировки. Записи WB этот сценарий не изменяет и отмену заказа не имитирует.

Новый флаг `WMS_KIZ_SORTING_ADMIN_REUSE_ENABLED=true` только нашей ВМС. Активная сборка, продажа, погашение, дубль, отсутствие точного движения и неподтверждённые/устаревшие ответы запрещают освобождение. Прежний путь отменённых заказов сохранён. Проданная ВМС не обновляется.

Меняются только `common/kiz-cancelled-reuse.js` и новый `common/kiz-sorting-return-proof.js`. Вызовы проверки прав и учёта в существующем `kiz-review-queue.js` сохранены без изменения. Полная source/runtime parity не заявляется; source/ содержит точные исходники этих двух модулей для компиляции CommonJS/ES2022.
