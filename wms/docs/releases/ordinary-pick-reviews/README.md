# Обычный отбор, проверки КИЗ и уведомления

Обычный подтверждённый отбор WB без КИЗ и SOS WB 2 теперь показывает «Найдено» после правильного ШК и «Упаковано» после физического подтверждения. После последнего товара заявка получает «Сдано» только вместе с успешным складским списанием. Используется существующий `finalizeWbOrderShipment`: блокировка заявки, факт отгрузки и движения остатков в одной транзакции; повтор не списывает товар снова. Смешанные, маркированные, неполные заявки, неизвестный источник и задания SOS не включаются в новую ветку. Старые заявки не закрываются массово задним числом.

Изменены `fbs-request-auto-status.ts`, новый `ordinary-unmarked-pick.ts` и подписи онлайн-отбора в `tsd-assembly.service.ts`. Флаг `WMS_FBS_UNMARKED_PICK_CLOSE_ENABLED` по умолчанию false; true только в образе нашей WMS. Общие модули потенциально затрагивают проданную WMS при переносе, поэтому флаг и runtime этого выпуска переносить туда нельзя.

Проверки КИЗ: отдельные закрытые details за последние семь суток по первому обращению, существующие решения и ограничения сохранены. История не удаляется. Список API отсортирован по createdAt/id по убыванию; пагинация прекращается на старой странице.

Уведомления: кнопка «Отметить все прочитанными», все страницы административной истории и непрочитанные клиентские уведомления. Используются существующие scoped API: административные отметки персональны; клиентские сохраняют существующую модель прочтения. Новые уведомления после начала операции остаются непрочитанными. До четырёх запросов одновременно, повторный клик блокируется, частичный сбой виден, счётчик обновляется после операции. Действующие дополнительные функции production-уведомлений сохранены точечным адаптером.

la_panthera: золотой колокольчик с контрастным счётчиком, три карточки мониторинга по верхнему краю; на узком экране перенос. Косметика ограничена темой и экранным режимом. Изменены `App.tsx`, компоненты `MarkAllNotificationsButton`, `markAllNotifications`, `KizReviewQueuePanel`, `KizReviewCard`, `reviewWeek` и `la-panthera-theme.css`.
