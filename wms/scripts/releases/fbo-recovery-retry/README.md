# Исправление повторов административной операции ФБО

Опубликовано в нашей WMS через PR451, 02.10.2026. Health-check и все хеши runtime проверены.

При PACK_UNITS/CLOSE_PICK внутренний executeAction перехватывал P2034 и повторял
операцию в той же транзакции, переданной recoverInTransaction. PostgreSQL уже
отменил эту транзакцию, поэтому следующая команда давала 25P02 и мешала внешнему
FboProblemsService.apply повторить всю операцию.

Runtime-патч устанавливает recoveryTransaction только на локальном экземпляре,
использующем внешнюю транзакцию. Исходный P2034 доходит до apply, который откатывает
всю операцию и повторяет её с прежним токеном предпросмотра в новой транзакции.
Обычные операции сохраняют прежние три попытки. Данные №1568 не изменялись.

База API: sha256:7713bd2033c56cb079b9ee2c1147be454cb3f87b177dca573cefb62c0b0388fb.
Кандидат: sha256:b5241036c24526715e4d880950f98f3ecf18fda00e6fea16be1ad390afc94209.
Разрешён единственный runtime delta: modules/tsd/fbo-two-stage.service.js.

sourceParityVerified=false: recoverInTransaction существует в проверенном runtime,
но ещё не сведён с историческим TypeScript. Поэтому сохранён воспроизводимый
patch.py с проверками якорей; полную сборку исходников публиковать нельзя.
TypeScript содержит то же условие владения повтором, без переноса остальных
несведённых частей сервиса.

Проданная WMS не обновляется. Новые флаги, миграции и изменения бизнес-данных
не требуются. Общий модуль сборки затронут только в обработке ошибок.

Проверки: runtime тест воспроизвёл 25P02 до фикса; после фикса 5 проверок прошли,
включая PACK_UNITS, CLOSE_PICK, обычные повторы и одну запись результата при
повторном запуске внешней транзакции. Два локальных теста TypeScript прошли.
Перед публикацией повторно проверить live image, PR и health-check; сохранить
предыдущий образ для отката. Runtime-тесты используют имитацию транзакций,
не изменяют рабочую БД и не заменяют подтверждение пользователя после выпуска.

Полный локальный прогон API: 2989 passed, 129 skipped; 269 файлов прошли, 7 пропущены. Отдельный kiz-duplicate.integration.spec.ts исключён: требуется выделенная тестовая БД.
